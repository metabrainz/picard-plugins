# Look Up with Harmony

## Overview

This plugin adds a right-click context menu option to look up releases on [Harmony](https://harmony.pulsewidth.org.uk/).

## Features

- Adds a "Look up on Harmony" option in the right-click context menu for albums, tracks, and clusters
- Automatically includes the barcode & MusicBrainz release ID in the lookup URL if available
- Opens the Harmony lookup page in your default web browser

## Usage

1. Load an album, track, or cluster in Picard
2. Right-click on the album, track, or cluster
3. Select "Look up on Harmony" from the context menu
4. Your browser will open to the Harmony lookup page with the lookup pre-filled
